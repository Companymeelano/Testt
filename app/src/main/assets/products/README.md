کالاهایی که از آجیل ساخته شده‌اند (کره بادام زمینی، روغن گردو، ویفر، بستنی، کیک، بیسکویت، شیر بادام)
همان تصویر ساده ساخته‌شده را نشان می‌دهند. عکس‌های عمومی بالا بدون نشان تجاری‌اند؛ عکس‌های اختصاصی پایین، عکس واقعیِ کالاهای مشخص‌شده‌اند.

ترتیب اولویت نمایش: عکسی که ویزیتور خودش ثبت کرده ← عکس خود کالا در آتیران (جدول ka_image، کم‌کم و فقط برای کارت‌های روی صفحه بارگیری و در حافظه گوشی نگه داشته می‌شود) ← عکس این پوشه ← تصویر ساده ساخته‌شده.
تطبیق کلمه‌ها در `MeelanoProductPhotos.keyFor()` است.

## عکس‌های اختصاصیِ بروشورهای ارسالی

برای کالاهایی که نام برند و مدل در فهرست آتیران آمده باشد، عکس اختصاصی قبل از عکس عمومی دسته انتخاب می‌شود:

|---|---|
| delbos_processed_plum.jpg | آلوچه/آلو فرآوری‌شده دلبوث |

| delbos_golden_plum.jpg | آلو طلایی یا برگهٔ زردآلو دلبوث |
| sahil_prune.jpg | آلوچه ساحل |

| shandiz_sun_plum.jpg | آلو سانتریزه شاندیز |

این عکس‌ها از بخش محصولِ عکس‌های ارسالی برش خورده‌اند؛ برچسب قیمت چاپ‌شده عمداً وارد عکس برنامه نشده تا با قیمت زندهٔ آتیران اشتباه نشود. دو PDF مربوط به کادر دوم/زاویهٔ جایگزین بودند و برای جلوگیری از تکرار، در کارت کالا عکس اصلی استفاده می‌شود. برای شکلات صبحانهٔ فرمند، تصویر PDF فاقد نمای تمیز و برچسب خوانای بسته‌بندی بود؛ بنابراین فعلاً عکس عمومی شکلات نشان داده می‌شود، نه یک تصویر ناقص یا دارای قیمت قدیمی.

افزودن عکس تازه: فایل `<key>.jpg` را اینجا بگذارید و alias/کلمه‌های آن را در `MeelanoProductPhotos.productSpecificKey()` یا قواعد دسته‌بندی اضافه کنید. تطبیق دقیق برند باید پیش از fallback عمومی باشد و برای هر alias تست واحد داشته باشد.
