# راهنمای اتصال و عیب‌یابی (میلانو منیجر)

## ۱. پیش‌نیاز شبکه

- گوشی و سرور SQL Server باید در یک شبکه باشند (WiFi داخلی شرکت یا VPN).
- پورت `1433` روی سرور باز باشد و SQL Server روی TCP/IP گوش بدهد.
- یک کاربر SQL با دسترسی **فقط خواندن** (`db_datareader`) روی دیتابیس آتیران بسازید.

## ۲. تنظیم اتصال در اپ

۱. وارد بخش **تنظیمات** شوید.
۲. **هاست** (IP سرور، مثل `192.168.1.50`)، **پورت** (`1433`)، **نام دیتابیس**،
   **کاربر** و **رمز** را وارد و ذخیره کنید.
۳. دکمه **تست اتصال** را بزنید؛ باید «اتصال برقرار شد • N جدول اصلی در دسترس» ببینید.
۴. نقطه بالای صفحه (کنار عنوان) وضعیت اتصال را نشان می‌دهد:
   سبز = وصل، قرمز = قطع.

> بدون اتصال واقعی، اپ داده‌ای نشان نمی‌دهد (حالت نمایشی/آفلاین ندارد).

## ۳. قفل مدیریتی (PIN)

- در تنظیمات می‌توانید PIN چهاررقمی فعال کنید؛ هر بار باز شدن اپ PIN خواسته می‌شود.
- برای حذف قفل، همان‌جا آن را خاموش کنید.

## ۴. خطاهای رایج

| پیام | علت محتمل | راه‌حل |
|---|---|---|
| `Network error` / timeout | IP/پورت اشتباه، VPN قطع، فایروال | IP را Ping کنید؛ پورت 1433 را با `telnet IP 1433` تست کنید |
| `Login failed` | کاربر/رمز اشتباه یا دسترسی ناکافی | کاربر SQL بسازید و `db_datareader` بدهید |
| «… در دیتابیس پیدا نشد» | اختلاف نسخه آتیران (جدول/ستون متفاوت) | طبیعی است؛ فقط همان کارت غیرفعال می‌شود. با `tools/probe_atiran.py` جدول‌های موجود را بررسی کنید |
| داده خالی ولی بدون خطا | فیلتر تاریخ/جست‌وجو محدود کرده | فیلتر (⚙) را بازنشانی کنید؛ بازه شمسی را چک کنید |

## ۵. بررسی سازگاری دیتابیس

روی یک سیستم که به SQL Server دسترسی دارد:

```bash
pip install pymssql
python tools/probe_atiran.py --host 192.168.1.50 --db Atiran --user sa2 --password '***'
```

خروجی نشان می‌دهد هر جدول کلیدی هست یا نه، چند رکورد دارد،
و ستون‌های اجباری‌اش موجود است یا نه.
