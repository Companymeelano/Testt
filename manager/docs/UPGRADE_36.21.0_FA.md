# تغییرات مدیر میلانو — نسخهٔ ۳۶٫۲۱٫۰

این ارتقا روی همان پروژهٔ مستقل «مدیر میلانو» انجام شده است؛ شناسهٔ بستهٔ نسخهٔ debug همچنان `ir.meelano.manager.debug` است. نسخه از `36.20.1` / کد ۵۲ به `36.21.0` / کد ۵۳ بالا رفته است. APK تازه با نام درخواستی `meelano-manager-v36-debug-6.apk` ساخته می‌شود؛ این نام به‌تنهایی اثبات نمی‌کند که فایل تاریخیِ `-6.apk` پیدا شده یا با آن باینری یکسان است.

## مالی و بستن روز

- جمع «نقد + کارت + حواله + چک» با مبلغ ثبت‌شدهٔ هر قبض دریافت/پرداخت مقایسه می‌شود.
- نتیجه فقط وقتی نمایش داده می‌شود که ستون‌ها/جداول لازم در schema زنده موجود باشند؛ schema ناقص به‌عنوان «نامشخص» نمایش داده می‌شود، نه صفر.
- اختلاف، هشدار بررسی است و به‌تنهایی خطا تلقی نمی‌شود؛ تخفیف یا سایر مبلغ می‌تواند اختلاف ایجاد کند.
- snapshot بستن روز، وضعیت availability دفاتر و ارقام تفکیک را نیز نگه می‌دارد.

## مدیریت و سابقهٔ اصلاحیه‌ها

- هر ثبت یا اصلاحیه در جدول جانبی افزایشی `MeelanoDailyCloseHistory` ثبت می‌شود.
- به‌روزرسانی تاریخچه و snapshot جاری در یک transaction انجام می‌شود؛ اگر یکی تأیید نشود، هر دو rollback می‌شوند.
- snapshot قبلیِ ساخته‌شده با نسخه‌های قدیمی هنگام اولین اصلاحیه به‌عنوان `legacy` به تاریخچه منتقل می‌شود.
- اگر دسترسی جدول تاریخچه نباشد، بستن اولیه مجاز است؛ اصلاح snapshot موجود قفل می‌شود تا نسخهٔ قبلی بی‌ردپا بازنویسی نشود.
- هیچ جدول یا سند اصلی آتیران در فرآیند بستن روز تغییر نمی‌کند.

## انبار و شمارش

- نشست فعال شمارش، شامل روز، انبار و اقلام، در حافظهٔ خصوصی اپ به‌صورت خودکار نگه‌داری و پس از بازشدن مجدد صفحه/اپ بازیابی می‌شود.
- گزارش تنها پس از ذخیرهٔ محلی و بازخوانی موفق از صف پیش‌نویس ثبت می‌شود؛ در صورت شکست، اقلام نشست باقی می‌مانند.
- پاک‌کردن نشست فعال با تأیید انجام می‌شود و به گزارش‌های قبلی/در صف همگام‌سازی دست نمی‌زند.
- ثبت همچنان فقط گزارش بررسی است؛ تا وقتی جدول تعدیل موجودی و schema آن تأیید نشده، موجودی آتیران با تأیید شمارش تغییر نمی‌کند.

## بررسی کیفیت

- تست‌های واحد برای محاسبهٔ مغایرت اجزای مالی و رمزگذاری/بازیابی نشست شمارش افزوده شدند.
- workflow نسخهٔ مدیر APK debug را جدا از flavorهای دیگر build می‌کند و package، شمارهٔ نسخه، امضا و تمامیت فایل را بررسی می‌کند.
