# تغییرات مدیر میلانو — نسخهٔ ۳۶٫۲۲٫۰

این ارتقا فقط روی پروژهٔ مستقل «مدیر میلانو» انجام شده است؛ شناسهٔ بستهٔ نسخهٔ debug همچنان `ir.meelano.manager.debug` است. نسخه از `36.21.0` / کد ۵۳ به `36.22.0` / کد ۵۴ بالا رفته تا APK تازه از build قبلی قابل‌تشخیص و نصب باشد. نام خروجی درخواستی حفظ شده است: `meelano-manager-v36-debug-6.apk`؛ این نام به‌تنهایی اثبات نمی‌کند که فایل تاریخیِ `-6.apk` پیدا شده یا با آن باینری یکسان است.

## اتاق فرمان خانه

- کارت خوشامدگویی مدیریتی با زمان روز، نقش فعال، تاریخ شمسی و نشان اختصاصی اضافه شد.
- میان‌بر افقی خانه، فاکتورها، خزانه، بستن روز، انبار و گزارش‌ها را با توضیح کوتاه و آیکن‌های برداری یکدست در دسترس می‌گذارد.
- مقصدهای میان‌بر بر اساس مجوز نقش جاری فیلتر می‌شوند؛ دسترسی‌ها و منطق داده/سرور تغییر نکرده‌اند.

## زبان بصری و ناوبری

- سرعنوان بخش‌های مدیریتی با آیکن موضوعی، رنگ معنایی و فاصله‌گذاری منظم نمایش داده می‌شود.
- نوار پایین آیکن برداری، نشانگر روشنِ بخش فعال و برچسب خواناتر دارد.
- صفحهٔ «بیشتر» از نشان‌های برداری و کارت‌های گروه‌بندی‌شده برای پیدا کردن مراکز تخصصی استفاده می‌کند.
- چیدمان از اجزای بومی Android و تم روشن/تاریک برنامه استفاده می‌کند؛ هیچ وابستگی UI تازه‌ای اضافه نشده است.

## بررسی کیفیت و تحویل

- نسخهٔ مدیر به‌طور مستقل build می‌شود؛ flavorها/پروژه‌های دیگر در این تغییر دست‌نخورده‌اند.
- workflow، تست‌های واحد Gradle، هویت package/version، امضای APK و تمامیت ZIP را بررسی می‌کند.
- APK نهایی در `dist/meelano-manager-v36-debug-6.apk` و اطلاعات build/hash در `dist/manager-v36-build-info.txt` قرار می‌گیرد.
