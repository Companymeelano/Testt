# تغییرات مدیر میلانو — نسخهٔ ۳۶٫۲۳٫۰

این ارتقا فقط روی برنامهٔ مستقل مدیر (`manager/app`) اعمال شده است: از `36.22.0` / کد `54` به `36.23.0` / کد `55`. شناسهٔ بستهٔ debug همچنان `ir.meelano.manager.debug` است؛ اپ یکپارچهٔ ریشه و flavorهای دیگر تغییر نکرده‌اند.

## اتصال و انتخاب دیتابیس

- ترتیب راه‌اندازی روشن شد: لایسنس، IP سرور، فهرست دیتابیس‌های سازگار، انتخاب دیتابیس و سپس صفحهٔ ورود.
- مسیر دستی فقط IP می‌گیرد؛ بعد از اتصال مستقیم، دیتابیس‌های دارای ساختار آتیران بررسی و در انتخاب‌گر نمایش داده می‌شوند.
- اتصال موجود مستقیم به SQL Server، driver و تنظیمات دسترسی آن تغییر نکرده‌اند؛ مسیر Wi‑Fi و انتخاب‌گر قبلی حفظ شده‌اند.

## ورود مدیریت و انبارداری

- حساب‌های ثابت محلی همین اپ برای مدیریت و انبارداری، پس از انتخاب دیتابیس استفاده می‌شوند؛ برای این دو نقش به جدول کاربران آتیران رجوع نمی‌شود.
- ورود مستقیم بدون حساب، از جمله مسیر قدیمیِ نبود جدول کاربران، بسته شد.
- تنظیم اتصال فقط وقتی کامل محسوب می‌شود که هم IP سرور و هم دیتابیس انتخابی ذخیره شده باشند.

## بررسی و تحویل

- آزمون‌های واحد مدیر، build مستقل، هویت package/version، امضای APK و سلامت ZIP در CI بررسی می‌شوند.
- نام فایل build: `dist/meelano-manager-v36-debug-7.apk`; اطلاعات build و SHA-256 در `dist/manager-v36-build-info.txt` ثبت می‌شود.
- این artifact از نوع debug است و جایگزین release امضاشدهٔ پایدار نیست؛ نصب روی نسخهٔ تولیدی یا حفظ امضای نصب قبلی تضمین نمی‌شود.
