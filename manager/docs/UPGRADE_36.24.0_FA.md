# تغییرات مدیر میلانو — نسخهٔ ۳۶٫۲۴٫۰

این ارتقا فقط برای برنامهٔ مستقل مدیر در `manager/app` است: از `36.23.0` / کد `55` به `36.24.0` / کد `56`. شناسهٔ بستهٔ debug همچنان `ir.meelano.manager.debug` است؛ اپ ریشه و flavorهای دیگر تغییر نکرده‌اند.

## پایداری و تشخیص خطا

- صف کارهای دیتابیس به ۱۲ درخواست منتظر محدود شد تا لمس‌های سریعِ تازه‌سازی و کندی سرور نتواند صف نامحدودِ callbackها را در حافظه جمع کند؛ در حالت شلوغی پیام قابل‌فهم نمایش داده می‌شود. صف اتصال هنگام خروج از صفحهٔ لایسنس نیز بسته می‌شود.
- علت دقیق هنگ یا بسته‌شدن بدون گزارش دستگاه قابل تأیید نیست و این تغییر، رفع قطعی همهٔ crashها را ادعا نمی‌کند.
- آخرین استثنای Java به‌صورت محلی و در فضای خصوصیِ بدون پشتیبان ثبت می‌شود. گزارش فقط نوع خطا، نسخه، thread و چند frame کد را نگه می‌دارد؛ پیام استثنا، IP، query، نام حساب یا رمز را ثبت نمی‌کند و خودکار جایی فرستاده نمی‌شود. از «تنظیمات ← گزارش خطای اخیر» می‌توان آن را دستی کپی یا پاک کرد.

## سرور، حساب و اندازهٔ صفحه

- در تنظیمات، «تغییر IP / دیتابیس» مستقیماً صفحهٔ ویرایش اتصال را باز می‌کند و IP ذخیره‌شده را برای ویرایش نشان می‌دهد.
- «قطع اتصال و پاک‌کردن IP» آدرس‌های ذخیره‌شده و دیتابیس انتخابی را پاک می‌کند؛ لایسنس، حساب محلی، و اطلاعات ورود SQL حفظ می‌شوند. پس از آن می‌توان IP دیگری وارد و دیتابیسش را دوباره انتخاب کرد.
- خروج/تغییر کاربر در منوی حسابِ سرصفحه قابل‌دسترسی است؛ در سرصفحهٔ فشردهٔ گوشی نیز دکمهٔ حساب نمایش داده می‌شود.
- قفل عمودی از صفحه‌های مدیر، ورود و اتصال برداشته شد؛ فرم ورود در تبلت/نمایشگر عریض با عرض حداکثر ۴۸۰dp وسط‌چین می‌شود. محدودیت عمودی اسکن بارکد و افقی داشبورد تلویزیون حفظ شده است.
- صفحهٔ اتصال با کارت راهنمای برجسته و دکمه‌های اصلی/ثانویهٔ واضح‌تر پرداخت شد.

## موارد حفظ‌شده و راستی‌آزمایی

- اتصال مستقیم فعلی به SQL Server 2014، درایور و روش ورود SQL تغییر نکرده‌اند؛ این تغییر معماری اتصال یا API نیست.
- منطق تاریخ، امضا، schema و flavorها تغییر نکرده‌اند. حساب‌های محلی مدیریت/انبارداری و کنترل session محلی نیز دست‌نخورده مانده‌اند.
- CI باید آزمون‌های واحد مدیر و build مستقل را اجرا کند، سپس هویت package، کد/نام نسخه، امضای APK و سلامت فایل را بررسی کند. artifact خروجی: `dist/meelano-manager-v36-debug-8.apk`; اطلاعات و SHA-256 در `dist/manager-v36-build-info.txt` ثبت می‌شود.
- این خروجی debug است؛ چون امضای release پایدار در دسترس نیست، آن را به‌عنوان update قابل‌نصب روی نسخهٔ تولیدی معرفی نمی‌کنیم.
